# Cresent Fractal Pentagon

An interactive study of the pentagon chaos game. Each point moves a chosen fraction of the way toward a randomly selected vertex, revealing the fractal pattern over time.

## Run locally

Open `index.html` in a browser. The page has no build step or external dependencies.

## Publish with GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and `/ (root)` folder, then save.

GitHub Pages will publish the site at `https://<owner>.github.io/<repository>/` after deployment completes.

## Controls

- Adjust point density and step ratio to explore different patterns.
- Choose a color study, pause or resume the drawing, and regenerate it.
- Export the current canvas as a PNG image.
